# Proposed features from the AI-provider benchmark (October 29)

These are things the scan-only runs of `openai-100`, `anthropic-100` and `gemini-30` (`docs/benchmarks/AI-PROVIDER-RESULTS.md`) showed Refit cannot fix safely under today's rules. Each one needs a product feature or an owner decision, not a rule tweak. None changes a safety gate by itself. Every one would be designed and checked on the dev sets.

1. **Endpoint-aware model swaps.** About 73 model-fix stops are "the repository mentions a custom endpoint" or "the client sets a custom base URL". Proposal: a client is treated as official when its `baseURL` comes only from the provider's documented environment variable or is unset, and a URL elsewhere in the repository that never reaches the client's options does not stop it. A proxy or other-provider URL still stops. Needs an owner decision, because it narrows a stop (AGENTS.md, indirect model sources).
2. **Completions to Chat Completions, for single-prompt calls only.** Legacy `completions.create` and `createCompletion` calls are stops (15 in `openai-100`). A mapping that rewrites a call with one `prompt` string and reads `.choices[0].text` to a one-message chat call that reads `.message.content` could be proven by the request proof. Multi-prompt, `logprobs`, `echo` and `suffix` calls stay stops.
3. **Assistants API sunset guide.** The Assistants API shut down on 2026-08-26, and Refit lists these calls for review only. Proposal: a report-only draft that links OpenAI's Responses migration guide and lists each thread, run and vector-store call, so an owner gets one actionable PR instead of a review finding.
4. **Sampling-aware SDK-major migrations.** `anthropic-2026-10-21-sampling` blocks every Anthropic SDK-major patch where a call sets `temperature`, `top_p` or `top_k` (68 stops in 25 rows). Proposal: block only the calls whose target model rejects the value written (per `data/model-parameters.json`), not the whole patch.
5. **Untracked model IDs in migrated files.** A correct `@google/generative-ai` → `@google/genai` swap can still send `gemini-pro`, which no Google page names by ID as shut down, so the sourced registry cannot list it (#404). Proposal (from #404): drafts list every model ID in a changed file that the registry does not track, as review information only, so the owner sees that the request may still fail.
6. **Python literal model swaps.** 48 affected Python rows can only be reported (decision 3). Proposal: an owner decision on Python edits for the narrowest case, a quoted model literal passed directly to `create(...)`, validated with the repository's own `pytest` in Docker.
7. **Tolerant scans.** One unreadable fixture `package.json` and one parse error fail a whole repository. Proposal: a file Refit cannot parse becomes a per-file stop, and the rest of the repository is still scanned.
