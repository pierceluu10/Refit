# Refit design system

## Direction

An engineering workbench with the breathing room of a startup landing page. The signature object is a migration moving from a provider specification through a blue Refit junction into a readable code review. The product earns attention through its mechanism rather than abstract AI imagery.

Geist Variable is used throughout the UI and headings. Geist Mono is reserved for paths, code, versions, and technical data. The display scale peaks at 88px; tracking stops at -0.04em. Body copy uses 16–18px with 1.6 line height. The content cap is 1160px, the spacing unit 4px, the control radius 6px, and major panels 12px.

## Motion

One coordinated hero entrance; a selectable workflow with autoplay once, pause, and replay; fast press feedback. Interaction duration 160ms, standard 220ms, entrance 600ms, step dwell 2200ms. Entrance easing is cubic-bezier(0.23, 1, 0.32, 1). Reduced motion disables spatial travel and autoplay. Backgrounded or offscreen examples do not advance.

## Surface behavior

Landing: Persuade. A centered typographic opening gives way to a broad interactive workflow canvas and code review. Lower sections vary between a process explanation, dark control/configuration panel, FAQ, and quiet final CTA.

Demo/workspace: Operate. Fixed navigation, aligned headers, searchable lists and explicit illustrative-data framing. Readable evidence and status take precedence over decorative motion.

Docs: Read. Persistent topic navigation, comfortable text measure, concrete limitations, copyable configuration, and links to the full specification.

Mobile collapses diagrams into a horizontal readable process, stacks editorial columns, and uses a disclosed navigation menu. Code regions scroll independently. Controls retain focus outlines and sufficiently large targets.
