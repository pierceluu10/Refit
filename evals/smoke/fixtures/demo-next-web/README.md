# demo-next-web (smoke fixture)

Illustrative Refit demo fixture. It stands in for the private sample repo `refit-dev/demo-next-web`
(MVP-PLAN.md section 5) in the MVP smoke test: a Next.js app on an older major, a GitHub Actions
workflow on old action versions, a Stripe checkout page, a cookie banner and a signup form. Not a
copy of the real repo. Nothing here is ever run.
