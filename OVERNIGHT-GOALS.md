# Overnight goals, ready to paste

One block per Claude Code session, in the order listed. Each session starts in your main clone of `pierceluu10/Refit`, in a mode that does not stop for approvals, after the [preflight](OVERNIGHT-AGENTS.md#preflight-each-person-before-starting). Generated from [Ready to paste](OVERNIGHT-AGENTS.md#ready-to-paste); if the two differ, that section wins.

## Pierce

Start P5 first and wait until it opens the board (about 5 minutes).

### P5

```
/goal Do lane P5 in OVERNIGHT-AGENTS.md at the root of origin/main (read the whole file first, then your lane twice), with $REFIT being the folder this session started in. Follow its shared rules, the benchmark protocol (GitHub Actions in refit-dev/refit-bench), the decision bar, the slices-and-merging rules, the file ownership table and the board. Go deep: take the biggest problem in your lane, understand every repository it affects, build the complete fix with real-snippet tests, measure it before and after on GitHub Actions, read every diff it produces, then take the next one. Use subagents for wide read-only work and verify their output. Answer your lane's design questions with evidence in docs/overnight/P5.md. Ship in slices: each slice is a PR against main with a current summary, and a READY <commit> comment when it meets its done criteria; after P5 merges it, continue from fresh origin/main. Do not stop to ask: record assumptions in the PR and keep going; record anything that needs the owner as Blocked with the exact error and move on. Start no new slice after 6 hours from T0 on the board, and hand off by 7 hours. This goal is met when the lane's "Done when" holds with evidence in merged or READY PRs (or each unmet item is recorded as Blocked with its cause), its "Keep going" items have been worked in order until the cutoff, docs/overnight/P5.md is complete, every PR summary is current, and every worktree this session created is removed. You are the integrator: open the board first, then run the merge loop all night, and end with the final runs, the docs and the morning summary by 9 hours from T0.
```
