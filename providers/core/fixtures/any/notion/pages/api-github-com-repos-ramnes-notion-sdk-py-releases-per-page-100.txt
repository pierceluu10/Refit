## 3.0.0 (3.0.0, published 2026-02-16T11:23:54Z)
https://github.com/ramnes/notion-sdk-py/releases/tag/3.0.0
Thanks to all the contributors for this new major version!

⚠️ Beware of the following breaking changes:

* `is_full_page_or_database` has been removed. Use `is_full_page_or_data_source` instead.
* `is_api_error_code` has been made private.

## What's Changed
* Added `intro-to-notion-api` example for Python SDK by @Sumeet213 in https://github.com/ramnes/notion-sdk-py/pull/297
* Added helper functions related to `data sources` in `helpers.py` and more namespace exports by @tsinglinrain in https://github.com/ramnes/notion-sdk-py/pull/299
* Fixed mypy compatibility with Python 3.14 by @Sumeet213 in https://github.com/ramnes/notion-sdk-py/pull/300
* Added OAuth token, introspect, and revoke endpoints by @Sumeet213 in https://github.com/ramnes/notion-sdk-py/pull/301
* Added move method to pages endpoint by @JJocelynH in https://github.com/ramnes/notion-sdk-py/pull/307
* Added error namespace and refactored `errors.py` following JS SDK implementation by @tsinglinrain in https://github.com/ramnes/notion-sdk-py/pull/308
* Added path traversal validation in `error.py` following notion-sdk-js by @tsinglinrain in https://github.com/ramnes/notion-sdk-py/pull/312
* Added support for Python 3.14 by @ramnes in https://github.com/ramnes/notion-sdk-py/pull/315

## New Contributors
* @JJocelynH made their first contribution in https://github.com/ramnes/notion-sdk-py/pull/307
