Twilio versions each product API separately in the URL path. The core REST API (Messages, Calls, Accounts, IncomingPhoneNumbers) lives under a dated path, `https://api.twilio.com/2010-04-01/...`; the older `2008-08-01` path reached end of life on December 15, 2023. Newer products use `v1`/`v2` on their own subdomain (for example `https://verify.twilio.com/v2/Services`, `https://messaging.twilio.com/v1/...`). A new path version or the removal of an old one is an `api-version` change; put the old and new paths in `affects.versions`.

Product end-of-life notices (Notify, Proxy, Authy, Programmable Chat, older Sync/Chat SDK versions and the like) are `product-shutdown`, with the EOL date as `effectiveDate`. Twilio sometimes extends or reverses an EOL (Programmable Video's 2026 EOL was withdrawn in October 2024), so read the latest notice before reporting one. Discontinued Event Streams event types and changed webhook or callback payloads are `webhook-payload`.

The twilio-oai and twilio-node changelogs list per-product spec changes; entries marked **(breaking change)**, removed paths, removed or renamed parameters and properties, and deprecated resources matter most. In `affects`, name REST paths (`/2010-04-01/Accounts/{AccountSid}/Messages.json`, `/v1/Replays`), resource and operation names (`twiml_session`, `StartConversation`), parameters and fields, and helper-library calls as code writes them (`client.messages.create`, `client.verify.v2.services`). Helper-library majors that drop runtimes or rename methods are `sdk-major`; set `affects.sdk` to the package (`twilio` on npm and PyPI, `twilio-ruby`, `com.twilio.sdk:twilio`, `Twilio` on NuGet, `twilio/sdk` on Packagist, `github.com/twilio/twilio-go`). Ignore console and UI changes, regional availability announcements, carrier and compliance news with no API change, minor spec formatting updates and marketing posts.
