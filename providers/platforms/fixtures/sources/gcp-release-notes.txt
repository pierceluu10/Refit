## Apigee Edge for Public Cloud

### Announcement

Scheduled maintenance of Management/Control Plane for the Apigee Edge for Public Cloud on November 6, 2026.

Scheduled maintenance of Management/Control Plane for the Apigee Edge for Public Cloud production will take place on Friday, November 6, 2026, from 9:00 PM PT to
10:00 PM PT (Saturday, November 7, 2026, from 5:00 AM UTC to 6:00 AM UTC). This
maintenance follows the monthly maintenance window schedule documented in the
Apigee Edge release notes archive.

During the scheduled maintenance window, the following services will be
temporarily unavailable, and attempts to access them will return a 4xx status
code:

- Management Services UI

- Management Services APIs

- Monetization Management APIs

- New proxy deployments

- DevPortal Service

- Microgateway Services

- Edge Query (Analytics Stats APIs)

Runtime API calls to deployed API proxies are unaffected. While access to
analytics queries may be temporarily unavailable during the maintenance window, all
analytics and metrics data from this period will be available once maintenance
ends.

## Data Studio

### Feature

You can now combine tables vertically in Data Studio blends by using the
Union merge operator, which appends rows across up to five tables and
removes duplicate rows. In addition, blend UI labels now use merge (such as
Merge another table, Merge conditions, and Hide repeated merge
fields) to encompass both join and union operations. For more information, see
How blends work in Data Studio and
Create, edit, and manage blends.

## Gemini Enterprise Agent Platform

### Feature

Gemini Omni 1.2 Flash

Gemini Omni 1.2 Flash
(gemini-omni-1.2-flash) is available in
General Availability (GA).
Gemini Omni 1.2 Flash is an omni-modal foundation model that processes text,
image, and video inputs to generate text and high-definition video with
synchronized audio through the
Interactions API.

Gemini Omni 1.2 Flash introduces the following capabilities:

- Standalone video upscaling: Upscale previously generated videos from
360p to 720p or 1080p, and from 720p to 1080p or 4K using task: "upscale".
See Upscale videos.

- Extended video generation and editing duration: Generate or edit videos
up to 15 seconds in length across text-to-video, image-to-video,
reference-to-video, and video editing tasks (up to 10 seconds for
first-and-last-frame interpolation and video extension).

- Reference-guided video editing and extension: Supply up to 2 reference
images along with an input video when editing or extending videos. See
Edit videos and
Extend videos.

- Deterministic generation and billing labels: Specify seed for
reproducible video outputs and attach custom labels to Interactions API
requests.

- Standard PayGo and Provisioned Throughput: Available with
Standard Pay-as-you-go (PayGo)
and
Provisioned Throughput
(685 tokens per second per GSU).

### Fixed

CodeMender updates (v0.18.0)

This release introduces updates to CodeMender:

- Verification tool-turn guardrails: Added exploratory tool-turn limits to cm verify sessions to prevent unbounded command execution loops.

- Release notes link in update prompts: Added a direct link to DevSite release notes when CodeMender prompts to update to a newer CLI version.

- Agent IAM diagnostic guidance: Added actionable roles/aiplatform.agentsUser IAM binding commands to CLI setup and error messages for service account and CI/CD environments.

- Bug fixes:

- Improved the reliability of agent sessions, including verification and resumed sessions.

- Improved compatibility across shell environments.

- Improved the sign-in flow during interactive activation.

- Improved error reporting when the service is temporarily unavailable.

- Includes security and stability improvements.

For more information, see the CodeMender documentation.

## API Gateway

### Announcement

Negative backend deadlines are no longer deprecated

The deprecation of negative backend deadline values announced on
October 23, 2026 is withdrawn. In an OpenAPI 2.0 x-google-backend
extension or a gRPC BackendRule, a negative deadline continues to
use the default deadline, the same as 0, and won't be rejected.
OpenAPI 3.x backends still reject a negative deadline.

For more information, see OpenAPI 2.0 extensions and OpenAPI 3.x extensions.

AlloyDB Express overview.

## Cloud Run

### Feature

Cloud Run ephemeral disk is in General Availability (GA). Ephemeral disk allows you to mount a volume that persists only for the duration of your service, job, or worker pool instance.

## Cloud SQL for SQL Server

### Feature

Cloud SQL for SQL Server now supports read pool autoscaling
(GA),
which helps you more easily manage your application's workload needs.

This feature automates read pool scale in and scale out operations based on one
or both of the following conditions:

- Allowed CPU usage of the read pool

- Allowed number of client connections to the read pool

## Gemini Enterprise

### Feature

Gemini Enterprise: Switch between teams in the mobile app

You can switch between multiple teams in the Gemini Enterprise mobile app
without logging out and rescanning the QR code. (Teams were previously called
instances.)

When you open a team for the first time, the mobile app saves it to your teams
list. Additionally, you can rename teams in the list and you can remove teams
from your list.

This feature is generally available (GA). For more information, see
Teams in Use the mobile
app.
