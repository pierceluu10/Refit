<html><body><p>Starting December 2, 2026, GitHub Actions will block <code>pull_request_target</code> events by default in all public repositories, unless an applicable Actions event policy explicitly allows them. Enforcement was previously scheduled for November 2, 2026.</p>
<p>GitHub introduced this default rule through workflow execution protections. The rule initially runs in evaluate mode, so you can see which workflow runs it would block before enforcement begins.</p>
<p>Private and internal repositories aren&rsquo;t affected.</p>

<p><code>pull_request_target</code> runs in the context of the base repository and can access its secrets. <html><body><p>We&rsquo;re adding IP ranges for GitHub webhook deliveries on github.com. The Meta API now includes these additional ranges in the <code>hooks</code> field.</p>
<p>If you maintain a static network allowlist for incoming webhook deliveries, add these CIDR prefixes alongside your existing webhook IP ranges to avoid rejecting deliveries:</p>
<ul>
<li><code>9.234.98.160/28</code></li>
<li><code>9.234.98.176/28</code></li>
<li><code>9.234.106.48/28</code></li>
</ul>
<p>If you already keep your allowlist up to date using the Meta API, no changes are needed for these additions.</p>
<p>These ranges apply to webhook deliveries on github.com across all plans, including GitHub Enterprise Cloud.</p>
<p>You can retrieve the current webhook IP ranges using the <a href="https://docs.github.com/rest/meta/meta#get-github-meta-information">Meta API</a> and follow the <a href="https://docs.github.com/webhooks/using-webhooks/best-practices-for-using-webhooks">webhook delivery best practices</a>.</p>

<p>Use project automations for repeatable tasks, such as creating a new promo video whenever a feature lands.</p>

<html><body><p>Enterprises working with a GitHub or Microsoft account team can now get Copilot included with GitHub Enterprise for every licensed user. Previously, you had to manage two things: how many Copilot seats you were paying for and how much AI usage those users consumed. With Copilot included in the platform, usage against your enterprise budget is the primary thing to manage.</p>
<p>Self-serve availability is coming in stages, and current self-serve subscriptions are unaffected. Copilot Business and Copilot Enterprise remain available.</p>
<p>Users in your enterprise account who do not hold a GitHub Enterprise license get the same Copilot access through Copilot Standalone, at $10 per user per month.</p>
<p>Copilot access through GitHub Enterprise and Copilot Standalone has the same features and models as Copilot Enterprise but does not include monthly AI credits per seat.</p>
