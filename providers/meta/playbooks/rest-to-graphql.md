# REST to GraphQL

Rarely applies: the Meta Graph API is already a single graph-style HTTP API (nodes, edges, `fields=`), not a REST API with a GraphQL successor. For path and field changes see `endpoint-removed` and `field-renamed`; for version moves see `api-version`. Use `meta_search_docs` if a change looks like this.
