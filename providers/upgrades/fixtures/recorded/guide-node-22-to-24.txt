<h3 id="platform-support"><a href="#platform-support">Platform support</a></h3>
<p>Node.js no longer provides <a href="https://nodejs.org/en/download">pre-built binaries</a> for:</p>
<ul>
<li>32-bit Windows (x86) as of Node.js 23.0.0.</li>
<li>32-bit Linux on armv7 as of Node.js 24.0.0.</li>
</ul>
<p>Pre-built binaries for macOS now require a minimum of macOS 13.5.</p>
<p>Pre-built binaries for Linux on arm64, ppc64le, s390x and x64 continue to be compatible with glibc 2.28 and above (no change from Node.js 22).</p>
<p>Please refer to <a href="#building-nodejs-from-source">additional notes if you are building Node.js from source</a>.</p>
<h3 id="breaking-changes"><a href="#breaking-changes">Breaking changes</a></h3>
<h3 id="openssl-35"><a href="#openssl-35">OpenSSL 3.5</a></h3>
<p>Pre-built binaries of Node.js 24 LTS, or builds using the default build configuration options, include OpenSSL 3.5. Node.js 24 LTS uses the default security level from OpenSSL 3.5 of <code>2</code>, which means that:</p>
<ul>
<li>RSA, DSA and DH keys shorter than 2048 bits and ECC keys shorter than 224 bits are prohibited.</li>
<li>Any cipher suite using RC4 is also prohibited.</li>
</ul>
<p>If you rely on older keys or weak ciphers, test your workloads against Node.js 24 builds (or adjust key/cipher choices) before upgrading.</p>
<h3 id="other-behavioral-changes-and-argument-validation"><a href="#other-behavioral-changes-and-argument-validation">Other behavioral changes and argument validation</a></h3>
<p>The release includes a number of behavior and validation changes (stricter <code>fetch()</code> compliance, AbortSignal validation, stream/pipe errors now throwing, changes to Buffer behavior, path handling fixes on Windows, test runner defaults, and more).</p>
<h3 id="cc-addons"><a href="#cc-addons">C/C++ addons</a></h3>
<p>Addons linking against V8 APIs may need updates for V8 13.6; C++20 support may be required where previously C++17 was used. Where possible, prefer NODE-API to reduce rebuild churn.</p>
<h3 id="building-nodejs-from-source"><a href="#building-nodejs-from-source">Building Node.js from source</a></h3>
<p>If you are building Node.js from source, you may need to update your compiler toolchain:</p>
<ul>
<li>For AIX and Linux platforms, the minimum supported version of <a href="https://gcc.gnu.org/">gcc</a> is 12.2.</li>
<li>For macOS the minimum supported version of <a href="https://developer.apple.com/xcode/">Xcode</a> is 16.1.</li>
</ul>
<p>Node.js&#x27; <code>configure</code> script will warn if you attempt to build Node.js with a compiler toolchain that does not meet the minimum supported version but will not actively prevent you from trying.</p>
