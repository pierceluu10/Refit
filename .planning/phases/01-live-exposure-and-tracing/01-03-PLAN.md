## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| repository files -> resolver | Untrusted source is parsed by the compiler API. Adversarial shapes can try to steer edits or make recursion explode |
| proposal patch -> draft PR | Edits become a human-reviewed draft after offline Docker validation (`refit serve --model-fixes`) |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-07 | Tampering | valuesOf shared sources | high | mitigate | Only literals proven to flow into a traced `model` are edited. Until plan 01-04, any pass symbol used other than once stops with the existing sentence |
| T-01-08 | Tampering | functions returning their parameter | high | mitigate | Call-context arguments only, and the function's pass is dropped outside its body. Task 2 `pick` test |
| T-01-09 | Denial of service | recursive resolver on adversarial repositories | high | mitigate | Per-request memo keyed by declaration, depth 10, work budget 2,000. Cut paths are recorded for plan 01-04's stop |
| T-01-SC | Tampering | npm/pip/cargo installs | high | mitigate | This plan installs no package. Any install task is out of scope and must stop at a blocking human checkpoint |
</threat_model>
