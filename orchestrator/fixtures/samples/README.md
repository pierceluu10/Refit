# Sample repo fixtures (illustrative)

Small stand-ins for the three Refit demo repos described in MVP-PLAN.md section 5. They are not the
real `refit-dev` repos: each holds only the files the offline scan reads (manifests, version files,
Dockerfiles, workflows, manifests) and a few lines of code with the call sites. Nothing here runs.
`usages.json` in each folder is the API usage map the offline inventory stub replays for it.
